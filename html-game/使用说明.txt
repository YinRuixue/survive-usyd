Survive USYD — HTML 游戏版

打开方法
完整 Python 版：双击项目根目录的 Start Game.command，自动启动并打开游戏。
游戏运行期间保持启动窗口打开；关闭服务可在窗口中按 Control+C。
存档由 Python 保存到 backend/data/survive.sqlite3，刷新后会恢复当前进度。

独立 HTML 离线版：解压整个文件夹，然后用 Chrome、Edge 或 Safari 打开 index.html。
请保持 index.html、各个 JS 文件、style.css 和 assets 文件夹在同一目录。
直接打开 index.html 时，使用浏览器本地存档；要使用 Python 后端，请从 Start Game.command 进入。
图片、字体和剧情均保存在本地，不需要互联网。Python 版不要用静态 HTTP 文件服务器启动。

操作
填写姓名，选择女玩家 / Noah 或男玩家 / Chloe，然后开始学期。
点击对话框继续；只有一个剧情推进选项时，也可以按空格或 Enter。
每周在 Weekly Plan 中安排三项活动，点击已选栏位可以替换。
Status 查看当前状态，Target 查看通关要求和已公布的分数，Takeaway 购买食物。
宿舍菜单和底部工具栏的 Save / Load 可打开存档 / 读档页面。
底部 Fullscreen 可切换全屏，New game 可重新开始。
底部 Audio 可独立开关背景音乐和按钮音效、调整各自音量；关闭面板或按 Esc 返回游戏。
首次点击或按键后开始播放原创循环音乐。切到其他标签页时暂停，返回后继续。
声音偏好会保存在当前浏览器，刷新或开始新游戏后仍保留；音频文件在本地，无需联网。

存档
提供 9 个独立的手动存档位，保存姓名、角色、剧情位置、数值、计划和分支选择。
点击 Save，选择一个空位即可保存；已有存档的栏位会先确认是否覆盖。
点击 Load 或标题页的 CONTINUE GAME，选择存档即可恢复。
存读档页面右上角 CLOSE、左下角 BACK 和 Esc 均可返回；确认框中的 Cancel 可取消操作。
开始新游戏和完成结局不会删除这 9 个手动存档。
原有自动存档继续保留，读档页底部的 RESUME AUTOSAVE 可继续最近一次自动保存。
Save / Load 右下角的 Export saves 可导出九个槽位与自动存档，Import saves 可导入备份。
从旧 HTML 迁移到 Python 版时，先在原浏览器的旧页面刷新并导出，再到 Python 页面导入。
导入只填补空槽位，已有存档不会被覆盖。
存档不会上传到网络，也不会在不同浏览器、设备或打开地址之间同步。
部分浏览器会限制本地文件的存储；如果底部提示 Saving unavailable，游戏仍可继续，但不会保留进度。

内容
从 O-Week、Week 1–13、期末周到学业 / 恋爱结局的完整流程。
沿用现有 Figma 的背景、立绘、剧情和分支；活动数值按 2026-10-30 的试玩反馈更新。
保留无恋爱支线、被拒、五种重复活动特殊结局及资源耗尽、考试 / 作业未通过的结局。
期中、小组作业和期末权重分别为 25%、25%、50%。

活动基础数值（Fitness 加成前）
Study：Knowledge +8，Energy −14，Stress +12。
Rest：Energy +28，Stress −3，主要恢复体力。
Gaming：Energy −2，Stress −24，主要缓解压力，不扣钱。
Work：Money +45，Energy −16，Stress +12。
Exercise：Fitness +10，Energy −8，Stress −10。
Group Work：进度 +10%，Energy −16，Stress +14。
小组作业从 Week 5 发布后即可提前完成，没有主角个人进度上限；只要尚未提交且小组总进度不足 100%，就可以继续安排 Group Work。总进度最多为 100%，不会重复计算队友后来提交的内容。达到 90% 可以通过，100% 获得 bonus。
与 Noah / Chloe / Cassy 出游：Money −15，Energy +12，Stress −10。
每 10 Fitness 提高 5% 的能量恢复和压力缓解；新增加的 Fitness 从下一周生效。
生活费、外卖、剧情事件、考试评分和坏结局条件保持原设定。
旧存档保留已获得的状态；之后执行的活动使用新数值。

本版支持真实姓名输入、9 个手动存档位、自动存档、存档备份、键盘推进和全屏。
迎新转盘从原有十种奖品中随机抽取，每种概率 10%，每次新游戏只能领取一次。
指针停下的位置、奖励页、绿色数值提示和 O-Week 总结会同步显示实际奖品。
抽奖结果在动画播放前保存，刷新或重复点击不会重复领取。旧版已经领取的餐饮券保留。

建议使用桌面或横屏浏览器。画面会按原来的 16:9 比例缩放。
